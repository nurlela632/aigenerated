Debugging AI-generated Python code

Start by reproducing the error with a minimal input and reading the complete traceback. Guessing from the symptom often leads to unrelated edits.

Check the environment

Confirm the Python version, installed packages, file paths, and data types. Many apparent logic errors are caused by mismatched assumptions.

Fix and verify

Write a failing test, make the smallest change, and run the full relevant test suite. Ask an assistant to explain the failure, not merely rewrite the file.
